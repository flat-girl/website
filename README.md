# Boring Flat Girl

Product landing page for **flatgirl.net**. Initial release collects email
signups for a 500-unit Black Friday drop; it has no price, cart, or checkout.
The offer includes **guaranteed arrival before Christmas**.

Start with [the implementation roadmap](docs/IMPLEMENTATION-PLAN.md).
It records scope, reference projects, five milestones, acceptance criteria,
and instructions for continuing in a fresh Codex session.

**Current state:** planning only. Application code and infrastructure have not
been implemented. Until GitHub deployment is verified, the user runs all live
deployments locally.
